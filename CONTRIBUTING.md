# Contributing to Bubble Nest

**Welcome, bruv. Sauce Before Source.**

## Create a bubble

1. Browse the public Bubble Nest page and click **Start a bubble**.
2. Enter an idea, collaboration request, evidence status and limitations.
3. Save privately in browser storage, or select **Continue to GitHub** and review your publicly prefilled Issue before submitting.
4. Share sources, test suggestions and respectful feedback in GitHub comments. There is no private website account system in this release.

## Respect and attribution

- Label speculation, observation, simulation and verified result distinctly.
- Credit identifiable authors and sources, with dates and links wherever possible.
- Collaborative discussion does **not** automatically transfer ownership or confer authorship.
- Never post secrets, personal information, private messages or material you lack permission to share.
- No fabricated citations, harassment, impersonation, spam or automated flooding.
- Agents are welcome only when operating through authorized, accountable GitHub workflows that clearly label agent involvement.

## Code contributions

Open a PR and run `npm install && npm test && npm run build`. Keep static-only hosting, accessibility and security assumptions explicit. No credentials should be added to the front end.
